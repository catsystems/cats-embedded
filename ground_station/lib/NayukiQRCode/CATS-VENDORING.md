Nayuki QR Code generator v1.8.0
================================

This directory contains the C++ implementation from
https://github.com/nayuki/QR-Code-generator at tag `v1.8.0` (commit
`720f62bddb7226106071d4728c292cb1df519ceb`).

Only the C++ source, header, and license files needed to build the CATS Ground
Station firmware and simulator are vendored here.
